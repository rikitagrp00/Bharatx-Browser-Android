# BharatX Browser — Android

**Version 1.38.0 · Developed by Nitaistudio · Made in India**

Application ID: `com.nitaistudio.bharatxbrowser`  
Support: `nitai.grp00@gmail.com`  
Developer website: https://www.trishabonlineservice.in/?m=1

This is the editable Android source project with BharatX branding, the supplied
logo, offline About/Privacy/Disclaimer pages, optional OpenVPN connections and an APK/AAB build workflow.

**VPN and ads:** Three-dot menu → BharatX VPN. France is Free; Lithuania is
Premium access in this app. One completed Appnext video unlocks one Premium
connection. An active monthly subscription disables banner, interstitial and
rewarded ads and bypasses the video gate. Price/currency come from Google Play.
Read [MONETIZATION.md](MONETIZATION.md) and [VPN_INTEGRATION.md](VPN_INTEGRATION.md).

Read [README_BHARATX_ANDROID.md](README_BHARATX_ANDROID.md) for Bengali build and
signing instructions. On GitHub, run **Build BharatX Browser Android**.

The source archive does not contain an APK/AAB. The build downloads the exact
Android Components revision recorded in `branding/build-lock.json`. An existing
upload key is required for signed release packages; an installable debug APK is
built separately for testing.
